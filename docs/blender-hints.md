# Blender Viewport & Camera Shortcuts

- `~` — View pie menu (View Camera / Top / Front)
- `Space` — Play / Pause timeline
- `N` — Toggle sidebar (Transform: exact X/Y/Z numeric coords)
- `G` — Move selected object / target / camera
- `G, Z, Z` — Dolly in/out along camera local axis (in camera view)
- `I` — Insert keyframe (Location) on active frame
- `Alt + I` — Delete keyframe on active frame
- `X` / `Delete` — Delete selected keyframe dot on timeline
- `Shift + S` — Snap menu (Cursor to Selected / Selection to Cursor)
- `Shift + Tab` — Toggle snapping (magnet); dropdown selects Vertex / Edge / Face
- `F3` — Operator search (e.g. `Revert`)
